# PeerJS Practice

A phone-to-PC live camera app built to practice WebRTC with PeerJS, React, TypeScript and Vite.

## Features

- PC shows its Peer ID and a QR code
- Scan the QR code to stream the phone camera to the PC
- Send text from the phone that floats up over the video
- Shows connected devices and handles disconnects

## Run

```
npm install
npm run dev
```
